# ThumbPreview — Free YouTube Thumbnail Previewer

Upload a YouTube thumbnail and instantly preview how it looks across real YouTube layouts: desktop home feed, mobile feed, dark mode, search results, sidebar, and Shorts.

**100% client-side.** Your images never leave your browser. Zero server cost.

## Features

- Drag-and-drop thumbnail upload (PNG, JPG, WebP)
- 7 YouTube layout mockups (desktop, mobile, dark/light, search, sidebar, Shorts)
- Editable video title and channel name with live preview
- Dark mode toggle
- Fully responsive (mobile, tablet, desktop)
- SEO-optimized with structured data
- Ad-ready with Adsterra placement slots
- Google Sheets webhook for anonymous usage analytics
- Visitor counter (today + total)

## Quick Start

```bash
# Local development — just open in browser
open public/index.html

# Or use a local server
npx serve public
```
